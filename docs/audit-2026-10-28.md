# 2026-10-28 修复与验收记录

## 配置与 Web

- 配置构造、读取和更新统一验证扫描参数：稳定等待须为有限且非负的数字，扫描间隔须为有限且大于零的数字；字符串解析、浮点溢出、NaN 与 infinity 均产生字段错误。
- 四个处理目录须为非空绝对目录路径。按解析后的路径检查符号链接别名、相同目录与危险包含关系；输出、归档和失败目录保持独立，但允许它们分别位于输入目录下。
- 更新先建立独立候选配置，验证和创建目录，再在配置文件同目录写入临时 JSON，flush/fsync 后通过 replace 发布；上述步骤成功才修改共享 Settings。mkdir、sync 或 replace 失败时保留旧配置实例与旧 JSON，清理临时文件。已创建的空目录不作为配置事务的一部分回滚。
- `/save` 在完整扫描锁内发布配置并清空队列，避免同一轮扫描混用新旧输入、输出与归档目录。字段或存储错误返回可读的 400 页面，保留路径、数值、复选框和跳过列表；成功保存维持原有重定向语义。
- 设置、日志、任务、关于及诊断页不再无条件读取扫描队列。控制台仅取等待摘要，候选页才逐项读取文件状态；控制台及候选页的队列读取仍可能等待正在执行的扫描。
- 大有限等待时间超出系统时间显示范围时降级显示说明，避免候选页面因时间转换溢出而异常。
- 诊断表单初始为空，示例仅作 placeholder；空白、相对或含空字符的路径在运行诊断前返回字段错误。
- 普通与强制扫描的反馈均以“候选”计数，覆盖 Live Photo 与普通媒体的处理尝试，不将计数宣称为合成成功数。
- 新生成的 PNG 图标统一用于 Web 导航、关于页、favicon 和 FPK 图标；保留 SVG favicon 路由及 MIME，并增加 PNG/ICO 兼容入口。现有页面 URL 与 Bootstrap CDN 保持兼容，版本显示随发布版本同步。

相关回归位于 `tests/test_settings_web_regressions.py`；该专项最新 20 项通过，另有 4 项既有 Web 测试实际执行通过，未以缺少 Flask 的跳过结果作为验收。

## 运行时、文件处理与去重

- 扫描轮次异常后重试；单个候选的 stat 或处理异常与其他候选隔离。隔离失败逐文件尽力处理，并保留原始失败原因和隔离错误。
- 文件对转换、普通媒体复制与诊断使用扫描树外的临时目录；仅将本次生成结果发布到目标目录，避免旧文件被误认为本次成功输出，并避免覆盖既有目标。
- 同文件系统发布使用原子操作；跨文件系统回退采用独占创建和失败清理。跨文件系统复制期间新目标可能被观察到，不宣称全程原子。
- 数据库和内存去重状态同时检查输出文件是否存在；输出丢失后可重建并更新既有签名记录。源文件消失时清理对应的完成缓存。
- 扫描保留同 stem 但未被选入文件对的普通媒体。诊断输出默认跟随实际配置和目录层级；最后诊断边界修复覆盖路径中的 `..` 与符号链接绕出配置范围。
- 停止服务时有界终止本服务启动的转换进程组；中止保留原件，不记为普通转换失败。主程序在 worker 结束后关闭数据库。
- 超大有限扫描间隔以平台 TIMEOUT_MAX 为单次等待上限，避免等待调用溢出。

相关专项位于 `tests/test_runtime_regressions.py`；子进程行为由短测试脚本验证，不等同于真实 MotionPhoto2 端到端验收。

## 保留的产品增强项与已知边界

- 手动扫描与诊断仍同步执行；异步任务、实时进度及取消入口属于后续产品设计。
- 任务分页与人工重试入口尚待设计。
- 登录、访问控制和 CSRF 保护尚待部署与产品策略确认，本轮未改变既有访问流程。
- 当前 Web 日志缓冲位于内存；日志持久化、检索与轮转属于后续增强。
- `/healthz` 当前仅表明 Web 进程可响应，即 **liveness**；它不代表数据库、转换依赖、目录权限或后台扫描的依赖健康。
